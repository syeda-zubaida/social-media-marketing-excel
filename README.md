# Social Media Marketing Analytics | Excel

This project analyzes social media marketing campaign performance using **Microsoft Excel**.

The workbook follows a complete analysis workflow from **data cleaning → PivotTable analysis → dashboard reporting**.

## Workbook Structure

The Excel workbook contains three main sheets:

- **Cleaning** – prepared and organized the raw campaign data for analysis
- **Pivot Table** – summarized campaign performance using PivotTables and calculated metrics
- **Dashboard** – presented the final findings through KPI cards and visual charts

## Project Objectives

The analysis was designed to evaluate:

- Campaign performance
- Return on Investment (ROI)
- Acquisition Cost
- Conversion Rate
- Clicks and Impressions
- Engagement Score
- Customer Segments
- Age and Gender Groups
- Geographic Performance
- Campaign Goals

## Skills Used

- Microsoft Excel
- Data Cleaning
- Sorting and Filtering
- PivotTables
- Calculated Metrics
- KPI Analysis
- Dashboard Development
- Marketing Analytics
- Data Visualization

## Analysis Workflow

1. Cleaned and organized the campaign dataset
2. Created PivotTables to summarize major performance metrics
3. Compared campaign results across demographics and locations
4. Evaluated acquisition cost, engagement, clicks and impressions
5. Developed an interactive Excel dashboard to communicate key insights

## Dashboard Highlights

The dashboard provides visual analysis of:

- Total Campaigns
- Impressions
- Clicks
- Acquisition Cost
- Engagement by Campaign Goal
- Campaigns by Age Group
- Gender-Based Analysis
- Geographic Performance
